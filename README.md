 CineVerse - Sistema de Gestión de Cine

Bienvenido a CineVerse, una aplicación web para administrar un cine de manera sencilla e intuitiva. 
El sistema permite gestionar desde el catálogo de películas hasta la venta de boletos, pasando por la configuración de salas y sus asientos.

¿Qué puedes hacer con la aplicacion CineVerse?

La aplicación está diseñada para dos tipos de usuarios, con funcionalidades específicas para cada uno.
Para todos los usuarios (USER)

    Iniciar sesión: Accede a tu cuenta personal para gestionar tus compras.
    Ver la Cartelera: Explora las películas disponibles, con detalles como duración, género y clasificación.
    Comprar Boletos: Elige una película, selecciona la sesión que mejor te convenga y escoge tu asiento favorito en un mapa interactivo de la sala. 
                  El precio se ajusta automáticamente según el tipo de entrada (Adulto, Menor, Estudiante).
    Mis Boletos: Revisa todas tus compras y reservas en un solo lugar, con el detalle de la función y el estado de cada boleto.

 Para los administradores (ADMIN)

    Panel de Administración: Un menú exclusivo con todas las herramientas para gestionar el cine.
    Gestión de Películas: Agrega nuevas películas a la cartelera, edita su información o actualiza su estado (activa/inactiva).
    Gestión de Salas: Crea y configura las salas del cine, definiendo su número, tipo y la cantidad de filas y columnas.
    Gestión de Asientos: Administra los asientos de cada sala. Puedes crearlos manualmente o usar la opción de generación automática para poblar toda una sala en segundos. Define si son asientos normales, VIP o preferenciales.
    Gestión de Sesiones: Programa las funciones para cada película, asignando sala, fecha, hora y precio base. El sistema controla la disponibilidad de asientos automáticamente.
    Administración de Boletos: Visualiza todas las ventas del cine, filtra por fecha, película o estado, y gestiona cancelaciones si es necesario. También puedes exportar un reporte con todos los boletos.
